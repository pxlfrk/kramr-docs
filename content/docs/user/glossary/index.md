# Glossar

| Begriff | Bedeutung |
| --- | --- |
| Admin | Rolle mit allen Rechten, dazu Nutzer, Rollen und Einstellungen. Siehe [Rollen und Rechte](../roles/index.md). |
| Anfrage | Eine Buchungsanfrage von einer Website. Sie ist noch keine Buchung; erst ihre Übernahme erzeugt einen Entwurf. |
| Anonymisieren | Persönliche Daten eines Kontakts entfernen, die Buchungen bleiben. Siehe [Kontakte anonymisieren](../anonymisation/index.md). |
| Archivieren | Material aus dem Betrieb nehmen, ohne es zu löschen. Die Historie bleibt. |
| Ausleihe | Eine Buchung mit Kontakt, bei der Material verliehen wird. |
| Belegung | Material, das durch eine genehmigte oder abgeholte Buchung fest gebunden ist. |
| Bestand | Stückzahl eines Mengenmaterials oder die Zahl der Einheiten. |
| Buchung | Eine Ausleihe oder eine Sperre mit Zeitraum, Positionen und Status. |
| Einbettung | Material und Anfrage auf der Website eures Vereins. |
| Einheit | Ein einzelnes, eigens bezeichnetes Stück, zum Beispiel ein bestimmtes Zelt. |
| Eigennutzung | Verleihart für Ausleihen der eigenen Organisation, ohne Tarif. |
| Entwurf | Status einer noch nicht bestätigten Buchung. |
| Kein Zugriff | Rolle ohne Rechte. Jedes neue Konto beginnt hier. |
| Kontakt | Eine Person, die ausleiht. |
| Konflikt | Hinweis, dass im Zeitraum mehr gebucht ist, als vorhanden ist. Siehe [Konflikte und Sperren](../conflicts-and-blocks/index.md). |
| Mengenmaterial | Material, das über eine Stückzahl geführt wird. |
| Position | Eine Zeile einer Buchung: ein Material mit Menge oder Einheit. |
| Pflicht-Set | Ein Set, das nur gemeinsam ausgeliehen wird. Siehe [Sets](../kits/index.md). |
| ReadOnly | Rolle, die alles ansehen, aber nichts ändern darf. |
| Set | Ein Material, das mehrere andere bündelt. |
| Sperre | Eine Buchung ohne Kontakt, die Material im Zeitraum belegt. |
| Staff | Rolle der Sachbearbeitung: Material, Kontakte und Buchungen verwalten. |
| Tarif | Preis für interne oder externe Ausleihe. Siehe [Preise und Tarife](../pricing/index.md). |
| Verleihart | Intern, extern oder Eigennutzung. Sie bestimmt den Tarif. |
| Vormerkung | Ein Entwurf: Er belegt nichts, wird aber bei Konflikten angezeigt. |
