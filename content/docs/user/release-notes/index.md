# Neuigkeiten

Die vollständige Liste steht in der Anwendung unter dem Eintrag „Changelog",
den du mit einem Klick auf die Versionsnummer oben rechts öffnest.
Veröffentlichte Versionen stehen außerdem auf der Seite „Releases" des
Projekts auf GitHub.

## Version 1.2

- **Buchungsanfragen von Websites:** Besucher einer Vereins-Website können
  eine Anfrage beginnen, erhalten einen Link per E-Mail, stellen Material und
  Zeitraum zusammen und reichen sie ein. Die Sachbearbeitung prüft sie im
  neuen Bereich „Anfragen".
- **Website-Einbindung:** Administratoren richten Einbettungen ein, wählen die
  gezeigten Kategorien und die Websites, die einbetten dürfen.
- **Online sichtbar:** Einzelne Materialien und Parameter lassen sich von
  jeder Online-Anzeige ausnehmen.
- **Changelog in der Anwendung:** Alle Nutzer mit einer Rolle können ihn lesen.
- **Lesbarer:** Größere Schrift, Eingabefelder und Schaltflächen; das dunkle
  Erscheinungsbild ist jetzt kühles Grau.
